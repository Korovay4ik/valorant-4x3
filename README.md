# Valorant-4x3 — настоящий стретч для Valorant (портативная версия)

Скрипт запускает **VALORANT в растянутом разрешении (true stretched)** на **любом ПК с Windows 10/11**, используя метод через «Диспетчер устройств», и **автоматически возвращает всё назад**, когда ты закрываешь игру.

Сторонние программы и правка памяти не используются — способ безопасный (не банный).

## Как это работает

Valorant читает **EDID монитора** (его «паспорт» с нативным разрешением) и **сам компенсирует пропорции**: при обычной смене разрешения растягиваются только HUD и прицел, а модели персонажей остаются нормальными — это «fake stretched».

Если отключить драйвер монитора в **Диспетчере устройств**, EDID исчезает, и Windows начинает использовать **generic-драйвер** («кабель воткнут, а что за монитор — неизвестно»). Valorant больше не может определить нативный дисплей и **растягивает всю картинку** — модели шире, чёрных полос нет. Это и есть **true stretched**.

## Требования

- Windows 10 или 11.
- PowerShell 5.1 (входит в Windows по умолчанию).
- Права **администратора** (скрипт сам попросит UAC — `Disable/Enable-PnpDevice` без них не работают).
- Установленный VALORANT через Riot Client.
- Целевое разрешение должно **существовать** в системе (см. ниже).

## Быстрый старт

1. Проверь/создай целевое разрешение (см. следующий раздел).
2. При необходимости открой `config.json` и поменяй `ResolutionWidth` / `ResolutionHeight`.
3. Двойной клик по **`Valorant-4x3.cmd`** → разреши UAC.
4. Играй. Когда закроешь Valorant — всё вернётся само.

Проверить, что всё настроено правильно, **ничего не меняя**, можно так (в PowerShell в этой папке):

```powershell
powershell -ExecutionPolicy Bypass -File .\Valorant-4x3.ps1 -DryRun
```

## Одноразовая настройка видеокарты (ВÁЖНО)

### NVIDIA

1. **NVIDIA Control Panel → Display → Change resolution → Customize** (кнопка «Customize…»)
   - Включи галочку **«Enable resolutions not exposed by the display»**.
   - **Create Custom Resolution…** → задай **ширину/высоту** целевого разрешения и **частоту** (например, 240 Гц) → **Test** → **OK**.
2. **Display → Adjust desktop size and position** (для игрового монитора):
   - Scaling mode: **Full-screen**
   - Perform scaling on: **GPU**
   - Поставь галочку **«Override the scaling mode set by games and programs»**
3. **Manage 3D settings → DSR Factors = Off**.

### AMD

1. **Radeon Software → Display → Custom Resolutions** → создай нужно разрешение.
2. Display → **GPU Scaling = Full panel** (растяжение на весь экран).

### Intel (встроенная графика на ноутбуках)

Если игровой монитор подключён к Intel, настрой scaling в **Intel Graphics Command Center**
(Display → масштабирование = **Stretch / Full panel**).

> `1440x1080` — ровно 4:3. «Про»-стретч, который часто используют игроки: `1440x992`,
> `1280x882`, `1566x1080` (пропорция ≈ 1.45). Подставь нужное в `config.json`.

## config.json — параметры

| Параметр | Тип | По умолч. | Описание |
|---|---|---|---|
| `ResolutionWidth` | число | `1440` | Ширина целевого разрешения. |
| `ResolutionHeight` | число | `1080` | Высота целевого разрешения. |
| `RefreshRate` | число | `0` | Частота обновления в Гц. `0` = максимальная доступная для этого разрешения. |
| `AspectRatioFill` | true/false | `true` | `true` = **Fill** (растяжение). `false` = Letterbox (чёрные полосы). |
| `DisplayMode` | строка | `WindowedFullscreen` | Режим экрана в игре: `WindowedFullscreen` / `Fullscreen` / `Windowed` / `Borderless`. Рекомендуется `WindowedFullscreen`. |
| `MonitorMode` | строка | `All` | Какие мониторы отключать: `All` — все активные; `Target` — только игровой; `None` — не трогать (для тестов). |
| `DisplayDevice` | строка | `""` | Принудительно задать адаптер, напр. `\\.\DISPLAY1`. Пусто = авто. |
| `MonitorHwid` | строка | `""` | Принудительно задать монитор по его ID, напр. `GSM5B8D` (LG UltraGear). Пусто = авто. |
| `LaunchValorant` | true/false | `true` | Самостоятельно запускать игру через Riot Client. |
| `RiotClientPath` | строка | `C:\Riot Games\Riot Client\RiotClientServices.exe` | Путь к `RiotClientServices.exe`. Если неверный — ищется автоматически. |
| `ValorantProcess` | строка | `VALORANT` | Имя процесса игры, за закрытием которого следит скрипт. |
| `LaunchTimeoutMinutes` | число | `5` | Сколько минут ждать появления процесса игры после запуска. |
| `LogToFile` | true/false | `true` | Писать лог в `%TEMP%\Valorant-4x3-portable.log`. |
| `PauseOnExit` | true/false | `true` | Оставлять окно открытым в конце (ждать Enter). |

**Автоопределение монитора** (когда `DisplayDevice`/`MonitorHwid` пусты) идёт в таком порядке:
`DisplayDevice` → `MonitorHwid` → монитор из настроек Valorant (`DefaultMonitorDeviceID`) → **основной монитор**.

## Аргументы командной строки

Аргументы **переопределяют** значения из `config.json`:

| Аргумент | Описание |
|---|---|
| `-Config <путь>` | Использовать другой файл конфига (по умолч. `config.json` рядом со скриптом). |
| `-ResolutionWidth <n>` / `-ResolutionHeight <n>` | Целевое разрешение. |
| `-RefreshRate <n>` | Частота (Гц). `0` = максимальная. |
| `-DisplayMode <строка>` | `Fullscreen` / `WindowedFullscreen` / `Windowed` / `Borderless`. |
| `-MonitorMode <строка>` | `All` / `Target` / `None`. |
| `-DisplayDevice <строка>` | Адаптер, напр. `\\.\DISPLAY1`. |
| `-NoLaunch` | Не запускать игру, только настроить и ждать. |
| `-NoPause` | Не ждать нажатия клавиши в конце. |
| `-DryRun` | Только показать, что будет сделано. Ничего не меняет, UAC не запрашивает. |

Примеры:

```powershell
# Предпросмотр без изменений
powershell -ExecutionPolicy Bypass -File .\Valorant-4x3.ps1 -DryRun

# Разово другой размер
powershell -ExecutionPolicy Bypass -File .\Valorant-4x3.ps1 -ResolutionWidth 1280 -ResolutionHeight 960

# Отключить только игровой монитор (безопаснее для ноутбуков)
powershell -ExecutionPolicy Bypass -File .\Valorant-4x3.ps1 -MonitorMode Target

# Свой конфиг
powershell -ExecutionPolicy Bypass -File .\Valorant-4x3.ps1 -Config .\my-config.json
```

## Что происходит по шагам

1. Читает `config.json` (и аргументы командной строки) — они переопределяют конфиг.
2. Запрашивает права администратора (UAC).
3. Сохраняет текущий режим дисплея и делает **бэкап** всех `GameUserSettings.ini`.
4. Проверяет, что целевое разрешение **существует**. Если нет — сообщает и **ничего не трогает**.
5. Отключает **остальные** мониторы (чтобы не мешали).
6. Переключает игровой монитор на целевое разрешение (пока его драйвер ещё активен — тогда кастомный режим доступен).
7. Отключает **сам игровой монитор** → исчезает EDID → **настоящий стретч**.
8. Прописывает в конфиг Valorant: разрешение, `Aspect Ratio = Fill`, `Display Mode`.
9. Запускает VALORANT (через Riot Client) и ждёт закрытия процесса.
10. **`finally` (всегда):** включает мониторы обратно → возвращает исходное разрешение → возвращает конфиг Valorant.

Откат срабатывает даже при ошибке или `Ctrl+C`.

## Если что-то пошло не так

Скрипт **всегда старается вернуть всё назад**. Но если он был прерван жёстко (закрытие окна, выключение ПК) и мониторы остались выключенными:

1. **Диспетчер устройств → Мониторы** → правый клик на устройстве → **«Включить устройство»**.
2. Либо просто **перезагрузи ПК**.

Если игра не растягивается:

- Разрешение **не создано** — создай его (см. раздел про настройку GPU).
- Нет галочки **«Override the scaling mode set by games and programs»** (NVIDIA) / GPU Scaling (AMD/Intel) =
  будут чёрные полосы.
- В самой игре проверь: **Video → Aspect Ratio = Fill**, **Display Mode = Windowed Fullscreen**.

## Частые проблемы

| Сообщение | Причина / решение |
|---|---|
| `Resolution WxH is not available …` | Целевого разрешения нет в системе. Создай его в панели видеокарты. Скрипт показывает список доступных режимов. |
| `ChangeDisplaySettingsEx = -2` | `DISP_CHANGE_BADMODE` — режим не принят драйвером. Обычно значит, что разрешение не создано/не применено. |
| `Elevation was cancelled or failed` | Отклонён запрос UAC. Запусти снова и нажми «Да». |
| `Riot Client not found` | Неверный `RiotClientPath`. Укажи правильный путь в `config.json`. |
| Игра растянулась, но с чёрными полосами | Не настроен scaling (Full-screen + GPU + Override / AMD GPU Scaling). |
| Куда угодно пропали ярлыки/окна | Нормально при отключении мониторов; после выхода всё возвращается. |

## FAQ

**Это безопасно / не забанят?**
Да. Никаких сторонних программ, инжектов и правки памяти — только стандартное «отключение устройства» в Windows. Так играть можно.

**Нужно ли отключать античит/Vanguard?**
Нет, ничего отключать не надо.

**Будет ли работать на AMD/Intel?**
Да. Разница только в том, где создавать кастомное разрешение и настраивать масштабирование (см. раздел про GPU).

**Почему скрипт отключает все мониторы (`MonitorMode = All`)?**
Так делает классический метод. Если на твоём ПК это создаёт проблемы — поставь `Target` (отключит только игровой монитор).

**Что если хочу просто посмотреть без изменений?**
Запусти с `-DryRun`.

**Можно ли выйти из игры и не восстанавливать?**
Нет — по задумке всё **всегда** возвращается. Так безопаснее.

**Куда сохраняется конфиг Valorant?**
`%LOCALAPPDATA%\VALORANT\Saved\Config\...\GameUserSettings.ini` — скрипт сам их находит и бэкапит.
